Odontograma — seleção por dentes e faces

Proposta para o item 5: o odontograma atual (32 dentes FDI, clique = dente inteiro) ganha seleção por face — mesial, distal, oclusal/incisal, vestibular e lingual/palatina. Clique nas regiões da coroa para marcar faces específicas e no número do dente para marcar/desmarcar o dente inteiro. Layout abaixo espelha o componente React existente (quadrantes, coroa + raiz, inferiores espelhados).

1 · Odontograma interativo (faces + dente inteiro)

As 5 regiões da coroa são clicáveis individualmente; o número abaixo de cada dente alterna o dente inteiro. O resumo usa a mesma linguagem dos chips da ficha.

2 · Leitura das faces (vista oclusal)

Cada coroa é desenhada como um quadrado dividido em 5 regiões. A posição de cada face acompanha o quadrante: mesial sempre voltada para a linha média; vestibular para fora do arco (topo nos superiores, base nos inferiores); lingual/palatina para dentro.

Dente 36 (molar inferior) — 5 faces
Oclusal ao centro (O), vestibular (V) para baixo (arcada inferior), lingual (L) para cima, mesial (M) voltada para a linha média.
Dente 11 (incisivo superior) — 5 faces
Mesmo esqueleto do molar, com o centro rotulado como incisal (I) e a face interna como palatina (P).

3 · Como aparece no atendimento e no orçamento

A seleção alimenta a linha do procedimento como lista de { dente, faces[] } — faces vazias = dente inteiro. Exibição em chips curtos, como já é feito hoje com o número do dente.
