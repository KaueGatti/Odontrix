Opção B — react-advanced-odontogram (biblioteca real, v2.4.0)

Este mockup renderiza a biblioteca de verdade (a mesma instalada no projeto — MIT, Zoltán Dul), com idioma pt-BR e numeração FDI: dentes anatômicos referenciados em literatura (9 templates), seleção por dente/face, estados clínicos completos, periodontograma e exportações. Clique nos dentes e explore a interface nativa dela.

Requer internet — a lib é carregada via CDN (esm.sh + jsDelivr) pinada na v2.4.0 (versão local do projeto). Se o painel abaixo não carregar, verifique a conexão. O que observar: fidelidade dos contornos, ergonomia da seleção por face, densidade visual (sidebar clínica) e o quanto do design system do Odontrix dá para preservar via temas (--odon-*).

Observações desta opção

  • Engine clínico completo: o estado é orientado a achados (cárie, restauração, endo, periodonto…) — “selecionar faces para uma linha de orçamento” precisa ser mapeado a partir do estado exportado (JSON/FHIR).
  • Uma instância por página (estado em singleton de módulo) — não permite dois odontogramas simultâneos (ex.: atendimento + dialog aberto ao mesmo tempo).
  • Peso: engine ~1,7 MB minificado + 56 KB de CSS (fontes de PDF são lazy-load).
  • Aparência própria — temas via variáveis --odon-* aproximam as cores do design system, mas não reproduzem o layout do Odontrix.
